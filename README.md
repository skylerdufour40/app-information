# GitHub Pages + Codespaces App Information PWA

1. Open the project in GitHub Codespaces.
2. Edit `index.html` and replace the six `Paste here` values.
3. Commit and push to GitHub.
4. In GitHub: Settings → Pages → deploy from the `main` branch/root.
5. Open the Pages URL in Safari on iPhone/iPad and choose Share → Add to Home Screen.

The page includes a web-app manifest, service worker, and Home Screen install button.
